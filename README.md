## 📦 Project Overview

The **Opticlair Admin Panel** is a fully functional backend dashboard built for managing your optical e-commerce store.  
It empowers admins to manage **products**, **inventory**, **orders**, **appointments**, and **users** in one centralized, secure interface.

> 🧠 Designed for modern commerce – **fast**, **responsive**, and **feature-rich**.

---

## ⚙️ Tech Stack

| Layer       | Technology            |
|-------------|------------------------|
| Frontend    | React + Vite + TypeScript |
| Styling     | TailwindCSS / Chakra UI |
| Backend     | Node.js + Express       |
| Database    | MongoDB (Mongoose)      |
| Auth        | JWT + Role-based access |
| Deployment  | Vercel / Render         |

---

## ✨ Key Features

### 🧑‍💼 Admin Dashboard
- View summary of all orders, products, users, and revenue
- Daily performance insights and analytics

### 🛒 Product Management
- Add, edit, or remove products
- Upload multiple product images
- Manage stock (sold, warehouse, in-store)

### 📆 Appointment Module
- View and manage customer appointments
- Filter by date and time
- Confirm, reschedule, or cancel bookings

### 🛍️ Orders & Payments
- View completed and pending orders
- Track payment status via Razorpay
- Customer detail view per transaction

### 🧾 Product Authentication
- Verify scanned product IDs and show details
- Upload bulk products via JSON or CSV
- Toggle product `status`, `stock`, `description`, and more

### 👥 User Management
- View registered users
- Admin-only access to CRUD operations
